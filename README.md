# حاويات برو — المرحلة الأولى (نسخة التجارب الحية المجانية)

نظام إدارة حاويات متعدد الشركات: Node.js + Express + Prisma + Supabase.
كل شيء في هذا الدليل **مجاني بالكامل** ومناسب للتجارب الحية الواقعية.

## ما الموجود في هذه النسخة

- شركات متعددة معزولة البيانات، كل شركة باشتراك له تاريخ انتهاء
- لوحة المدير العام: إنشاء شركة، تمديد سنة، **إيقاف / إعادة تفعيل** مع بقاء البيانات
- فحص يومي تلقائي: تذكير سداد قبل انتهاء الاشتراك بأسبوع، وإيقاف تلقائي بعد الانتهاء
- تنبيهات استحقاق الحاويات: قبل **يومين** من الاستحقاق، تتكرر **كل 6 ساعات** حتى «تم الاطلاع» أو كتم الطلب
- طلبات بأنواعها (إنزال/رفع/تبديل/نقل/دورة مشروع)، برقم عقد أو بدون، مع **3 أرقام تواصل**
- التقاط **موقع العمل** من جوال منشئ الطلب (زر "استخدم موقعي الحالي") ورابط توجيه خرائط قوقل
- مستخدمون بأدوار (مدير، موزع، محاسب، سائق) ولغة لكل سائق (تمهيداً للإشعارات متعددة اللغات)

## الخطوة 1 — قاعدة البيانات على Supabase (مجاني)

1. أنشئ حساباً في supabase.com ثم **New project** — اختر منطقة Frankfurt (الأقرب للسعودية) وكلمة مرور قوية للقاعدة واحفظها.
2. من **Settings → Database → Connection string**:
   - انسخ رابط **Transaction pooler** (منفذ 6543) وضعه في `DATABASE_URL` مع إضافة `?pgbouncer=true` في نهايته.
   - انسخ رابط **Session pooler** (منفذ 5432) وضعه في `DIRECT_URL`.
3. انسخ ملف `.env.example` باسم `.env` واملأ القيم، وغيّر `JWT_SECRET` لأي نص عشوائي طويل.

## الخطوة 2 — التشغيل محلياً

يلزم Node.js إصدار 18 أو أحدث (من nodejs.org).

```bash
npm install          # تثبيت الحزم
npm run db:push      # إنشاء الجداول في Supabase
npm run db:seed      # بيانات البداية (مدير المنصة + شركة تجريبية)
npm start            # تشغيل الخادم على http://localhost:3000
```

حسابات البداية (غيّرها فوراً بعد أول دخول):

| الحساب | الجوال | كلمة المرور | يفتح |
|---|---|---|---|
| مدير المنصة (أنت) | 0500000000 | admin1234 | لوحة المدير العام |
| مدير الشركة التجريبية | 0511111111 | owner1234 | لوحة الشركة |

ستجد في الشركة التجريبية طلباً يستحق غداً — افتح تبويب التنبيهات وسترى تنبيه «خلال يومين» يعمل فعلياً، وجرّب «تم الاطلاع» و«كتم التنبيه».

## الخطوة 3 — تجربة حية من جوالك فوراً (نفق كلاودفلير المجاني)

خاصية تحديد الموقع لا تعمل إلا عبر HTTPS، والنفق يحل ذلك بأمر واحد بدون حساب ولا دومين:

```bash
# تثبيت cloudflared مرة واحدة (ويندوز: winget install Cloudflare.cloudflared)
cloudflared tunnel --url http://localhost:3000
```

سيظهر رابط مثل `https://random-name.trycloudflare.com` — افتحه من أي جوال وجرّب
زر «استخدم موقعي الحالي» من موقع العمل فعلياً. (الرابط يتغير كل تشغيل — للتجارب فقط).

## الخطوة 4 — الرفع على GitHub

```bash
git init
git add .
git commit -m "المرحلة الأولى — حاويات برو"
# أنشئ مستودعاً خاصاً (Private) على github.com ثم:
git remote add origin https://github.com/USERNAME/hawiyat-pro.git
git push -u origin main
```

ملف `.env` مستثنى تلقائياً من الرفع (داخل `.gitignore`) — لا ترفع أسرارك أبداً.

## الخطوة 5 — نشر مجاني برابط ثابت على Render

1. سجّل في render.com بحساب GitHub → **New → Web Service** → اختر المستودع.
2. الإعدادات: Build Command = `npm install && npx prisma db push`، Start Command = `npm start`، الخطة = **Free**.
3. أضف متغيرات البيئة (Environment): `DATABASE_URL` و`DIRECT_URL` و`JWT_SECRET` بنفس قيم `.env`.
4. بعد دقائق يصبح لديك رابط ثابت `https://hawiyat-pro.onrender.com` بـ HTTPS — كل `git push` ينشر تلقائياً.

ملاحظتان عن الخطة المجانية: الخدمة تنام بعد 15 دقيقة خمول وتستيقظ خلال ~30-60 ثانية عند أول زيارة (مقبول للتجارب)، والنوم يوقف المهام المجدولة مؤقتاً — لكنها مكتوبة بحيث تفحص كل شيء فور الاستيقاظ فلا يضيع تنبيه. عند الانتقال للإنتاج الحقيقي: خطة Render المدفوعة (7$) أو خادمك الخاص بنفق كلاودفلير دائم.

## بنية المشروع

```
hawiyat-pro/
├── prisma/schema.prisma   ← الجداول: شركات، فروع، مستخدمون، حاويات، طلبات، تنبيهات
├── src/
│   ├── server.js          ← نقطة التشغيل
│   ├── auth.js            ← الدخول JWT، الأدوار، عزل الشركات، فحص الاشتراك
│   ├── cron.js            ← الاستحقاق كل 6 ساعات + الاشتراكات يومياً
│   ├── seed.js            ← بيانات البداية
│   └── routes/
│       ├── admin.js       ← لوحة المدير العام
│       └── company.js     ← حاويات وطلبات وتنبيهات ومستخدمو الشركة
└── public/                ← صفحات الدخول ولوحتي المدير العام والشركة
```

## المراحل القادمة (حسب وثيقة REQUIREMENTS.md)

تطبيق السائق PWA بالصور والتتبع اللحظي Socket.IO، رفع الصور إلى Supabase Storage،
إشعارات واتساب، الإشعارات متعددة اللغات للسائقين، الموارد البشرية والأسطول وعداد الزيت، الفوترة والتقارير.
